## mascot6699.github.io

This repository contains the source code and content of my personal blog, [mascot6699.github.io](https://mascot6699.github.io). 
The blog is built with Gatsby.

### Getting started

To run the blog on your local machine, you need to have Node.js and yarn, npm installed. Then, follow these steps:

1. Clone this repository: `git clone https://github.com/mascot6699/mascot6699.github.io.git`
2. Install the dependencies: `yarn install`
3. Create a `.cache` folder in the root directory: `mkdir .cache`
4. Start the development server: `yarn run develop`
5. Open your browser and go to http://localhost:8000 to see the blog.
6. To push the blog for production, you need to have a `gh-pages` branch first, then run: `yarn run deploy`
